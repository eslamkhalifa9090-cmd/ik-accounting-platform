# منصة Mr. Islam Khalifa | Accounting

منصة تعليمية بحسابات للمتدربين، شغالة على Cloudflare Pages + D1 (مجاني).

- **الموقع الرئيسي** (`/`): صفحة الأكاديمية، ومعاها قسم "المنصة التعليمية" فيه المسارات (المتاح وقيد الافتتاح قريباً).
- **صفحة الكورس** (`/course?c=financial`): النبذة، المستويات بعناوينها ومقدماتها، نظام الامتحانات، والباقات بالسعر والخصم وزر الاشتراك على واتساب.
- **المتدرب**: دخول بالميل أو رقم التليفون (`/login`)، لوحة تقدم (`/dashboard`)، المستويات (`/learn`)، عارض PDF محمي بعلامة مائية باسم المتدرب (`/level`)، امتحانات (`/exam`)، شهادة إتمام (`/certificate`) وصفحة تحقق (`/verify`).
- **الأدمن** (`/admin`): إضافة المتدربين وتفعيل الكورسات، الأسعار والخصومات، رفع الـ PDF، الأسئلة (أو لصقها من Excel)، الإعدادات وخلفية الشهادة.

## قواعد المنصة

- مفيش تسجيل ذاتي. الأدمن بس هو اللي بيعمل حسابات المتدربين.
- كل متدرب بيقدر يدخل من جهازين بالكتير (الجهاز التالت بيخرج أقدم جهاز).
- المستوى بيفتح لما المتدرب ينجح في امتحان المستوى اللي قبله (والتراكمي لو موجود). النجاح = أكتر من نسبة النجاح (50% افتراضياً)، والمحاولات مفتوحة، والأسئلة بتتسحب عشوائي من بنك الأسئلة وترتيب الاختيارات بيتغير.
- الـ PDF بيتحول في المتصفح عند الرفع لصور صفحات، ومحفوظ في قاعدة البيانات. المتدرب بيشوف الصفحات بس، من غير تحميل ولا نسخ نص، وعليها اسمه ورقمه.
- امتحان المستوى بيفتح بعد ما المتدرب يخلص المادة العلمية كلها (زرار "خلصت المادة دي" في آخر صفحة).
- كل امتحان ليه مدة بالدقايق (الافتراضي 15 للمستوى و40 للتراكمي، و0 = من غير وقت). لما الوقت يخلص الامتحان بيتسلم لوحده.
- كل محاولة بتجيب الأسئلة اللي المتدرب لسه ماشافهاش، ولما البنك يخلص الدور بيبدأ من الأول. وبعد التسليم بيشوف أخطاؤه والتوضيح.
- الـ PDF بيفتح على آخر صفحة المتدرب وقف عندها، من أي جهاز.
- الشهادة بتطلع لما المتدرب يعدي كل امتحانات الكورس، وعليها QR بيفتح صفحة التحقق، والجهة المصدرة بتتعدل من الإعدادات.

## التشغيل على Cloudflare (مرة واحدة)

1. اعمل حساب مجاني على [Cloudflare](https://dash.cloudflare.com/sign-up).
2. **قاعدة البيانات:** من Storage & Databases ← D1 ← Create، سميها `ik-platform`. الـ Database ID متسجل في `wrangler.toml`.
3. **الجداول:** افتح قاعدة البيانات ← Console، والصق محتوى `migrations/console/setup_once.sql` (سطر واحد فيه كل الجداول والبيانات الأولية) واضغط Execute.
4. **الموقع:** من Workers & Pages ← Create ← Pages ← Connect to Git، واختار الريبو `ik-accounting-platform`. سيب Build command فاضي، وخلي Build output directory = `public`.
5. **كود الإعداد:** من Settings ← Variables and Secrets، ضيف `SETUP_KEY` كـ Secret بأي كلمة سر طويلة إنت بس اللي تعرفها، واعمل Redeploy.
6. افتح `https://<اسم-المشروع>.pages.dev/setup` واعمل حساب الأدمن بكود الإعداد. الصفحة دي بتتقفل بعد أول حساب أدمن.

أي تعديل يتعمل على الريبو بيتنشر لوحده.

> **ملحوظة عن الـ Console:** الـ D1 Console بيلزق الملف في سطر واحد، فأي سطر تعليق `--` بيبوظ الملف كله. علشان كده استخدم الملفات اللي في `migrations/console/` (سطر واحد من غير تعليقات): `setup_once.sql` لقاعدة جديدة، وملفات التحديث زي `0003_phase1.sql` لقاعدة شغالة. الملفات دي بتتولد بـ `python3 scripts/console_sql.py`.

## تحديث قاعدة شغالة

كل تحديث فيه تغيير في قاعدة البيانات ليه ملف في `migrations/console/`. نفذه في الـ Console **قبل** ما تعمل Merge للتحديث، وكل ملف يتنفذ مرة واحدة بس.

## التشغيل محلياً (للمطور)

```bash
npm install
echo "SETUP_KEY=local-setup-key" > .dev.vars
npm run db:local
npm run dev
```

بعد كده افتح `http://localhost:8788/setup`.
